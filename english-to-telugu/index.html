What setup requires

Model downloads and startup time depend on the connection and device. Browser microphone permission is needed for speech input. Offline use begins after the required assets are cached, and support depends on the browser and available resources.

What makes Telugu translation difficult

Translation must preserve meaning, names, numbers, negation and formality. Telugu fluency alone does not prove faithfulness, so evaluation needs native-speaker review alongside automatic metrics.

How we assess model changes

We compare upstream baselines and adapted models using complete evaluation references and recorded settings. A low training loss or a successful fine-tuning run does not establish better translations.

Current experiments do not establish state-of-the-art performance. A checkpoint must be benchmarked, reviewed and shown to run in the browser before it can replace the live model.

Feedback

If recognition or translation fails, note the device, browser and example input when contacting us on X. Avoid sharing private recordings or personal information in public feedback.
