Method

How this works

Translation scores use one set of references and one scorer, with full results and limits on the Research page. Sizes were read from model files on Hugging Face. We add models only with a real file and a score we can reproduce. Scores do not replace review by Telugu speakers, and memory, speed and battery use on named devices have not been measured yet.
